
# 🧾 Namma Santhe Ledger – Android App

A simple and efficient Android application built for small vendors and shop owners to manage daily transactions digitally.

The app focuses on:
- Clean UI
- Fast performance
- Easy transaction management
- Digital record keeping

---

# 🚀 Features

- 📱 Clean and simple UI
- 🔐 User login system
- ➕ Add customer transactions
- 📊 Transaction history tracking
- ⏰ Weekly reminder notifications
- 👤 Profile management
- * 🔥 Firebase integration
* ☁️ Cloud backup
* 📄 PDF report export
* 🔍 Search and filter options
* 🌙 Dark mode
* 🌐 Multi-language support

---

# 🛠️ Tech Stack

| Technology | Used |
|------------|------|
| Language | Kotlin |
| Architecture | MVVM |
| UI Design | XML Layouts |
| Background Tasks | WorkManager |
| Notifications | Broadcast Receiver |
| Storage | Firebase & Local Storage |

# ⚙️ Setup Instructions

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Preethamo9/NammaSantheLedger.git
```

Or download ZIP from GitHub.

---

## 2️⃣ Open in Android Studio

1. Open Android Studio
2. Click **Open**
3. Select the project folder
4. Wait for **Gradle Sync** to complete

# 📦 Modules

## 🔐 LoginActivity

Handles user login authentication.

## 🏠 MainActivity

Main dashboard for managing transactions.

## 👤 ProfileActivity

Manages user profile details.

## ⚙️ SettingsActivity

Handles application settings.

## 🔔 ReminderReceiver

Triggers reminder notifications.

## ⏰ WeeklyReminderWorker

Schedules weekly reminder notifications.

# 🎯 Purpose

This app helps small businesses replace manual bookkeeping with digital transaction records.

Benefits:

* Faster transaction management
* Organized records
* Easy access to history
* Better reminder management
